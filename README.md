# NOVA AI — Video Enhancer

واجهة أولية لموقع عربي لتحسين الفيديو، مبنية باستخدام Next.js.

## تشغيل الموقع محليًا

1. ثبّت Node.js (الإصدار 20 أو أحدث): https://nodejs.org
2. فك ضغط المشروع.
3. افتح Terminal داخل مجلد المشروع وشغّل:

```bash
npm install
npm run dev
```

4. افتح http://localhost:3000

## نشر الواجهة على الإنترنت

1. ارفع مجلد المشروع إلى GitHub.
2. افتح https://vercel.com وسجّل الدخول عبر GitHub.
3. اختر Add New → Project، ثم اختر مستودع المشروع.
4. اضغط Deploy.

## مهم: محرك الذكاء الاصطناعي غير مربوط بعد

هذه النسخة تحتوي على واجهة رفع ومعاينة الفيديو وإعدادات التصدير فقط. زر التحسين يعرض تنبيهًا واضحًا؛ لا يدّعي أنه عالج الفيديو.

لجعل التحويل حقيقيًا، يلزم ربط backend آمن بخدمة/سيرفر GPU يدعم:
- AI upscaling (مثل Real-ESRGAN أو نموذج فيديو أحدث)
- Frame interpolation (مثل RIFE)
- FFmpeg لتجميع الفيديو والصوت والتصدير
- تخزين مؤقت آمن وروابط تنزيل

لا تضع مفاتيح API في كود المتصفح. ضعها في متغيرات بيئة السيرفر. يجب أيضًا تحديد حدود حجم الملف، مدة الفيديو، وحذف الملفات المؤقتة تلقائيًا.

## هيكل المشروع

- `app/page.tsx` — واجهة الموقع
- `app/globals.css` — التصميم
- `app/layout.tsx` — بيانات الصفحة واتجاه العربية
